# How It Works — Competitor 3: GitBook (Numbered Step Cards)

## Overview

Light-themed "How it works" section from GitBook. Uses a **centered headline + horizontal row of 5 numbered cards**. Clean, structured, and highly scannable.

---

## Layout

- **Centered header block** at the top: small label → large headline → subtitle
- Below: **5 cards in a single horizontal row**, evenly spaced
- Each card is a vertical block: **large number (01–05)** → **bold title** → **description paragraph**
- Cards appear to share a single rounded container (one large card with internal dividers, or individual cards flush against each other)
- The container has a **very subtle border** and **lightly tinted background** (warm off-white / light beige)

## Typography

- **Section label ("HOW IT WORKS")**: all-caps, very small (~11–12px), letter-spaced, orange/coral accent color — acts as a category tag
- **Main headline**: large (~36–42px), bold, dark/black, serif or display font, centered
- **Subtitle**: ~16px, regular weight, medium grey, centered, 1–2 lines
- **Card numbers (01–05)**: large (~28–32px), bold, **orange/coral accent** color — the main visual anchor per card
- **Card titles**: ~16–18px, bold, dark/black
- **Card descriptions**: ~13–14px, regular, dark grey, 3–5 lines

## Color

- **Background**: white or very light off-white
- **Card container background**: slightly warmer off-white / cream (#f5f1ed or similar)
- **Text**: black/dark charcoal for headings, medium-dark grey for body
- **Accent**: **orange/coral** used exclusively for the numbers and the section label — nothing else
- **Border**: very subtle light grey (#e0d8d0) around the card container, 1px, rounded corners

## Spacing

- Header block has generous top/bottom padding (~60–80px)
- Cards have internal padding (~24–32px)
- Clear gaps between cards achieved through padding or subtle dividers
- Overall section padding is moderate (~80–100px)

## Patterns & Principles

- **Explicit numbering (01–05)**: unlike the other competitors, this uses bold numerals to explicitly sequence the steps — makes order obvious at a glance
- **Horizontal card row**: optimizes for scanning — user can read all 5 step titles in a single left-to-right sweep
- **Accent color = numbers only**: the orange is used with extreme restraint — only on the step numbers and section label
- **Single container**: the cards feel unified (one big rounded box with divisions) rather than floating separately — conveys a cohesive process
- **Top-down hierarchy in each card**: number → title → description, consistent across all cards
- **No icons**: relies entirely on numbered headings rather than illustrative icons

## Key Takeaways

1. Numbered cards (01–05) provide the clearest sequential hierarchy of all competitors
2. Horizontal layout works well for a moderate number of steps (5)
3. Using the accent color only on numbers creates a strong visual rhythm
4. Single container unifies the steps into a perceived "process"
5. Light neutral palette keeps focus on content without visual noise
