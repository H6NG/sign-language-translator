# How It Works — Competitor 4: GitBook (Feature Cluster with Central Visual)

## Overview

Light-themed feature/capabilities section from GitBook. Uses a **central product visual** surrounded by **4 feature cards** arranged in a 2×2 grid around it. Not strictly a "How it works" stepper, but functions as one.

---

## Layout

- **Centered header block** at the top: large headline → subtitle → outlined CTA button
- Below: a **3-column layout** — left column (2 features stacked), center column (large product visual), right column (2 features stacked)
- Feature cards are positioned to **flank the central image**, creating a balanced, symmetrical composition
- The central visual is a **rich product mockup** with layered UI elements, badges, and avatars — it's the focal point
- Each feature card: **small icon** → **bold title** → **description paragraph**

## Typography

- **Main headline**: large (~36–42px), bold, dark/black, centered
- **Subtitle**: ~15–16px, regular, medium grey, centered, 2 lines with an em-dash
- **Feature titles**: ~16–18px, bold, dark/black
- **Feature descriptions**: ~13–14px, regular, dark grey (#555–#666), 2–4 lines
- CTA button text: medium weight, dark

## Color

- **Background**: white
- **Text**: dark/black for headings, medium grey for body
- **Central visual**: vibrant **orange/coral** as the dominant color — 3D-rendered swirl element with gradient, overlaid with white UI cards, icons, and avatar circles
- **Icons**: monochrome line icons in a **subtle rounded square container** (light grey background with thin border)
- **CTA button**: outlined, dark text on white, subtle rounded corners — not filled
- No accent color on the text itself — the visual does all the color work

## Spacing

- Header block has large padding (~60–80px)
- Feature cards have generous vertical spacing between the two rows (~60–80px)
- The central image dominates ~40% of the width, with feature columns each taking ~30%
- Internal feature card spacing: ~12–16px between icon, title, and description

## Patterns & Principles

- **Central visual as anchor**: the product mockup is the hero of the section — feature cards orbit around it like satellites
- **Symmetrical balance**: 2 features left, 2 features right, image center — creates visual harmony
- **Icon containers**: each icon is inside a **rounded square with light fill and thin border** — subtle but consistent
- **No numbering or sequence**: this is a feature showcase rather than a process flow — all four points are equal, not sequential
- **Color contained to visual**: the vibrant orange exists only in the central image — text and icons remain monochrome
- **CTA above the features**: "Learn more" is positioned after the headline, not at the bottom — invites clicks early

## Key Takeaways

1. Central visual with flanking feature cards is a strong layout for product-capability sections
2. Keeping vibrant color confined to the illustration/mockup prevents overwhelming the text
3. Consistent icon style (rounded square container) creates cohesion across features
4. Symmetrical 2+2 grid is balanced and easy to scan
5. Works best for non-sequential features; not ideal for step-by-step processes
